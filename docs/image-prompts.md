# Binaafy — image prompts

55 prompts for the new site. Each prompt is self-contained: copy the whole block,
including the style sentence at the end, so every image matches.

**How to deliver:** keep the filename exactly as written (e.g. `hero-bygg.jpg`),
generate at the largest size your tool allows, and put everything in one folder.
Crop to the ratio given. Pick the best one when a prompt gives you four variants.

**Where they go:** `public/images/`. The site looks for each name with any of
`.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`, so the extension doesn't matter. Until a
file exists, its slot shows a grid placeholder with the file name on it. In
development a new file shows up on reload; for production, rebuild.

**Rules that keep it premium:**
- No people's faces, no text or logos anywhere, no readable text on screens.
- Scandinavian / Swedish west coast, not American suburban.
- Muted palette: oak, limestone, off-white plaster, charcoal grey.
- Orange appears as one small accent in about a third of the images, never more.
- Reject any image with bent vertical lines, warped hands, or HDR look.

## J. Do not generate: photograph these yourself

These have to be real, or the site is showing work and people that don't exist.

- **Projects** — one cover plus a before and after per project, named after the project:
  - `projekt-villa-sondrum.jpg`, `projekt-villa-sondrum-fore.jpg`, `projekt-villa-sondrum-efter.jpg`
  - `projekt-radhus-vallas.jpg`, `projekt-radhus-vallas-fore.jpg`, `projekt-radhus-vallas-efter.jpg`
  - `projekt-tillbyggnad-fyllinge.jpg`, `…-fore.jpg`, `…-efter.jpg`
  - The three projects above are placeholders from the old site. Replace them with real jobs
    (tell me the name, place, service and a one-line description) before launch.
- **Team portraits** (4:5): `team-mohamed.jpg`, `team-abdulmalek.jpg`, `team-ibrahim.jpg`.
- **Software case** (4:3): `case-binaafy-sajten.jpg` — a real screenshot of this site.

**Photo tips so they match the generated images:**
- Shoot in daylight on an overcast day, lights off. Avoid flash.
- Hold the phone at chest height and keep vertical lines straight (turn on the grid).
- Clear the room first: fewer objects looks more expensive.
- For before/after, stand in exactly the same spot both times.
- Team: plain wall, window light from the side, same background for all three.
- Shoot landscape (4:3) and send the originals, not WhatsApp copies.
